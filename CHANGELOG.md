# AttendanceJournal PWA V5.3.4

- Недельное расписание показывает и использует максимум 3 пары (1–3) с понедельника по субботу.
- Для конкретной даты сохранена возможность назначить дополнительные пары 4–6.
- Отметка НБ теперь предлагает только пары, реально назначенные на выбранную дату; разовые пары 4–6 тоже доступны.
- «Весь день» выбирает все фактические пары выбранной даты, а не все 6 слотов.
- Старые записи НБ не теряются при редактировании: сохранённые ранее пары остаются доступными для изменения, даже если текущий график больше их не содержит.
- Word и его формат не изменялись.
