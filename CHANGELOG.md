# CHANGELOG

## V5.5.0

- Обновлена документация проекта: `README.md`.
- Удалён `QA-REPORT.md`.
- `README-START.md` заменён на `README.md`.
- Добавлена конфигурация `config.json` с `AdminMode: 0`.
- В истории переработаны представления по месяцу и по дню: дата, ФИО, часы, изменение записи.
- Редактирование НБ из истории использует основное окно НБ.
- Добавлено добавление НБ задним числом за день и диапазон дат.
- Для диапазона дат пары определяются по расписанию каждого дня.
- Добавлено подтверждение уважительной причины.
- Поддержано подтверждение отдельной записи через окно НБ.
- Добавлена отметка продолжения болезни на конец месяца (`прод. бол.`).
- В обычной ведомости в дневных клетках используется только `НБ`.
- В примечании обычной ведомости используются только `Р` и `прод. бол.`.
- Убрано перечисление номеров пар из примечания ведомости.
- Убраны сокращения `Б` и `С` из примечания ведомости.
- Обычная ведомость сжата под одну страницу Word.
- Исправлены размеры и переполнение блока даты в окне НБ на узких экранах.
- Убраны лишние технические и демонстрационные тексты из интерфейса.
- Эмодзи в интерфейсе заменены на текстовые/типографские символы.
- Service Worker обновлён до кэша V5.5.0.
