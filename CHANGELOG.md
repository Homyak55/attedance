# AttendanceJournal PWA V5.4.4

- Усилена нормализация старых/импортированных записей НБ: учитываются только пары 1–6.
- Старые записи, в которых сохранены только часы, корректно восстанавливаются до 1–6 пар (максимум 6 пар).
- При восстановлении backup сначала загружается конфигурация пар, затем нормализуются отметки НБ, чтобы данные не зависели от текущей конфигурации устройства.
- Версия Service Worker обновлена до V5.4.4.

# AttendanceJournal PWA V5.4.1

## Исправления и изменения

- Переработано окно отметки НБ: теперь это стабильная центральная карточка, без нижнего выезжающего окна.
- Причины НБ отображаются компактно: С / Б / Р сверху, «Неув / без причины» снизу.
- Выбор «Семейные обстоятельства», «Болезнь» или «Распоряжение» автоматически выбирает все пары, которые есть в расписании выбранной даты; отдельную пару можно снять вручную.
- Кнопка сохранения НБ сделана крупнее и закреплена в нижней части окна.
- Пустые ячейки календаря ведомости теперь нажимаются: можно открыть любой день и добавить НБ даже если ранее за этот день ничего не отмечалось.
- Backup убран из основного меню и перенесён в «Настройки».
- Добавлен статус студента «Многодетный».
- В разделе «Ведомость» добавлена отдельная кнопка формирования ведомости многодетных.
- Ведомость многодетных формируется отдельным Word-файлом: + если студент не отмечен отсутствующим, − если есть НБ; выходные/дни без занятий выделяются красным и не входят в количество дней.
- Статус «Многодетный» и вся новая информация сохраняются в backup.
- Service Worker cache обновлён до V5.4.1.
