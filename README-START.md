# AttendanceJournal PWA V5.3.4

## Важное
- Недельное расписание: максимум 3 пары (1–3), с понедельника по субботу.
- Для отдельной даты можно заменить занятия и дополнительно назначить пары 4–6.
- «Нет занятия» означает, что для этого слота на конкретную дату занятие не назначено.
- В окне НБ доступны только фактически назначенные на выбранную дату пары. Поэтому при дне с тремя занятиями приложение не предлагает отметить четыре-шесть пар.
- «Весь день» выбирает все фактические пары выбранной даты.
- Разовая замена конкретной даты не меняет недельный шаблон.
- Раздел «Группа» не содержит настройки количества/времени/предметов пар.
- Word остаётся в прежнем формате ведомости и не получает данные расписания.

Для обновления достаточно заменить файлы приложения новой версией; данные хранятся локально и мигрируются автоматически.
