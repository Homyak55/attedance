# AttendanceJournal PWA V5.3.3

## Важное
- Расписание содержит 6 фиксированных пар (1–6) с понедельника по субботу.
- «Нет занятия» означает, что в этой ячейке пары предмет не назначен.
- Разовая замена на конкретную дату не меняет недельный шаблон.
- Раздел «Группа» больше не содержит настройки количества/времени/предметов пар.
- Word остаётся в прежнем формате ведомости.

Для обновления достаточно заменить файлы приложения новой версией; данные хранятся локально и мигрируются автоматически.
