# Посещаемость

## О проекте

**Посещаемость** — офлайн-приложение для старосты группы. Оно предназначено для ежедневной фиксации НБ, ведения истории, работы с расписанием и автоматического формирования ведомости посещаемости.

Приложение рассчитано на работу с телефона и компьютера и не требует отдельной серверной части для обычной работы.

## Возможности

### Сегодня
- список студентов группы;
- отметка НБ по конкретным парам или за весь день;
- выбор причины: семейные обстоятельства, болезнь, распоряжение или без причины;
- изменение уже сохранённой отметки;
- расчёт часов по количеству пропущенных пар.

### История
- просмотр НБ по месяцу;
- просмотр НБ по конкретному дню;
- просмотр истории по предмету;
- выбор одного студента или всей группы;
- редактирование существующих записей;
- добавление НБ задним числом за день или диапазон дат;
- подтверждение уважительной причины после получения подтверждения;
- отметка продолжения болезни на конец месяца.

### Расписание
- библиотека предметов;
- недельное расписание с понедельника по субботу;
- замены на конкретную дату;
- дополнительные пары 4–6 на отдельный день;
- выходные и дни без занятий.

### Ведомость посещаемости
- выбор месяца;
- расчёт итоговых часов по дневным отметкам;
- разделение уважительных и неуважительных часов по статусу подтверждения;
- в дневных клетках отображаются только НБ;
- в примечании используются только `Р` и `прод. бол.`;
- продолжение болезни можно указать на конец текущего месяца, даже если следующий месяц ещё не заполнен;
- обычная ведомость формируется целиком на одной странице Word.

### Ведомость для многодетных
- отдельное формирование документа;
- `+` для питания и `−` для отсутствия;
- выходные и дни без занятий выделяются в документе;
- состав студентов берётся из отметки «Многодетный».

### Группа
- добавление, изменение и удаление студентов;
- массовая загрузка списка ФИО;
- отметка студента как многодетного;
- настройка данных учебного заведения и группы.

### Резервная копия
- создание JSON backup;
- восстановление данных из backup;
- в резервную копию входят группа, студенты, НБ, история, расписание, настройки и отметки продолжения болезни.

### Настройки
- светлая тема;
- тёмная тема;
- системная тема;
- установка приложения на iPhone.

## Как работает НБ

Староста отмечает только факт отсутствия и количество пропущенных пар. Количество часов рассчитывается приложением: одна пара — 2 часа.

Уважительные часы не считаются подтверждёнными автоматически. Для причины «болезнь», «семейные обстоятельства» или «распоряжение» запись можно подтвердить позже через историю. До подтверждения часы относятся к неуважительным, после подтверждения — к уважительным.

## Продолжение болезни

Если студент продолжает болеть после окончания месяца, в истории текущего месяца устанавливается отметка «Прод. бол.». В ведомости этого месяца в колонке «Примечание» появляется `прод. бол.`. В ведомости следующего месяца отдельная отметка не добавляется.

## Запуск локально

Проект является статическим веб-приложением. Для локальной проверки нельзя открывать `index.html` напрямую через `file://`, потому что Service Worker и manifest требуют HTTP(S).

В каталоге проекта можно запустить:

```powershell
python -m http.server 8080
```

После этого открыть `http://localhost:8080`.

## Установка на iPhone

Открой адрес приложения в Safari → «Поделиться» → «На экран Домой» → добавь приложение.

## Структура

- `js/app.js` — основная логика;
- `js/storage.js` — сохранение данных;
- `js/docx.js` — генерация Word;
- `js/exporter.js` — работа с файлами;

- `manifest.webmanifest` — параметры веб-приложения;
